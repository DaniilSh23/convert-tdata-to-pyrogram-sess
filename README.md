# Проект для конвертации папок tdata приложения Telegram в файлы сессии для библиотеки pyrogram

### Принцип работы:
Дело нехитрое: берём папку tdata, конвертируем её в файл сессии telethon через одну хорошую библиотечку, затем нужные данные из файла сессии telethon записываем в нужные места в файле сессии pyrogram. Спасибо за внимание.

## Подготовка к работе
- Используем python 3.10
- Устанавливаем зависимости `pip install -r requirements.txt`

## Конвертация из TDATA в файлы сессий telethon и pyrogram
- Проверяем, что в корне проекта есть такая папка `raw_converter/tdata_to_sessions/` (если нет, то создаем)
- Кладем в `raw_converter/tdata_to_sessions/` папки с TDATA. В общем виде две папки TDATA должна иметь такой путь относительно корня проекта: 
  * `raw_converter/tdata_to_sessions/<какое-либо имя аккаунта 1>/tdata/...`
  * `raw_converter/tdata_to_sessions/<какое-либо имя аккаунта 2>/tdata/...`
- Запускаем файл main.py `python3 main.py`
- Наблюдаем за работой, по итогу сконвертированные файлы сессий будут лежать в следующих папках:
  * Файлы сессий Pyrogram: `raw_converter/res_sessions/pyrogram_sessions`
  * Файлы сессий Telethon: `raw_converter/res_sessions/telethon_sessions`

### ! Обратите внимание, что для корректной работы необходимо использовать ```Pyrogram==2.0.106```. При использовании файлов сессий Pyrogram с более поздними версиями библиотеки, были замечены проблемы в работе. Возможно, это связано с измененной структурой таблицы БД SQLite, коими являются файлы сессий.
